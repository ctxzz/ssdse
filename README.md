# SSDSE（教育用標準データセット）配布

このリポジトリは、独立行政法人統計センターが公開している SSDSE（教育用標準データセット）を、
浜松医科大学 データサイエンス授業の教材として再配布しているものです。

## ファイル一覧

| ファイル | 内容 | データ単位・件数 | 列数 | 対象期間 | ヘッダー |
|---|---|---|---|---|---|
| `SSDSE-A-2026.csv` | 市区町村別データ（基本項目） | 市区町村 × 1,741件 | 128 | 2020年ほか | `header=2` |
| `SSDSE-B-2026.csv` | 県別推移（時系列） | 47都道府県 × 12年（564件） | 112 | 2012〜2023年 | `header=1` |
| `SSDSE-C-2026.csv` | 家計消費（品目別支出） | 全国＋県庁所在市 48件 | 229 | 2023〜2025年 | `header=1` |
| `SSDSE-D-2023.csv` | 社会生活統計指標（学習・スポーツ等） | 全国＋都道府県 × 男女別（144件） | 124 | 2021年 | `header=1` |
| `SSDSE-E-2026.csv` | 都道府県別データ（基本項目・少項目） | 全国＋47都道府県 48件 | 95 | 2024年ほか | `header=2` |
| `SSDSE-F-2023v3.csv` | 気象データ（月別平年値） | 県庁所在市 × 月・年（611件） | 46 | 1991〜2020年 | `header=1` |

- いずれも元データ（.xlsx）と同じ構造を維持しています。
- **ヘッダーが2種類あります。** 1行目は必ず項目コードです。
  - `header=1` のファイル：2行目が日本語列名、3行目以降がデータ。
  - `header=2` のファイル（A・E）：2行目に年度、3行目に日本語列名、4行目以降がデータ。

## Colab での読み込み方

```python
import pandas as pd

base = 'https://raw.githubusercontent.com/ctxzz/ssdse/main/'

# header=1 のファイル（B・C・D・F）
df_b = pd.read_csv(base + 'SSDSE-B-2026.csv', header=1)

# header=2 のファイル（A・E：年度行があるため）
df_a = pd.read_csv(base + 'SSDSE-A-2026.csv', header=2)

df_b.head()
```

`header=n` は「（0始まりで）n行目を列名として使う」という指定です。上記の表の「ヘッダー」列に合わせてください。元のSSDSE形式に準じています。
